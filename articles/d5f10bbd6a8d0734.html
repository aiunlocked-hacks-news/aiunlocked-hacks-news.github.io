180B Parameters, 32GB of RAM: Pushing MoE Inference to the Limit with Transformers

Experts are 90%+ of a MoE model's weights, so a 180B model like this one can run on a GPU with much less memory. Before committing to Strata, I looked at what llama.cpp, vLLM and Transformers do when a MoE model doesn't fit. A GPU expert cache ( --moe-cache-mib ) just landed, but it fragments the graph (2 splits per token become 50) and loses ~10% even when everything fits.

vLLM 's --cpu-offload-gb N puts N GB of weights in pinned RAM, and kernels read them in place over PCIe. Transformers offloads through Accelerate ( device_map="auto" , offload_folder ), one module at a time: hooks copy its weights to the GPU before forward . To try it, install Transformers from that PR: Then, moving from OLMoE to the real target, Qwen3.8-Flash-Next: That repo holds the output of the project's conversion script : the dense weights, the experts quantized to 3 bits, and the n-gram table.
