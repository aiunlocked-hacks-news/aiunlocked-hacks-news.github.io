📋 Quick Command Reference

📁 Files & Directories

ls List files
ls -la Detailed list with hidden
cd dir Change directory
pwd Print working directory
mkdir dir Create directory
touch file Create empty file
cp src dest Copy file
mv src dest Move / rename
rm file Remove file
find . -name "*.txt" Find files

📄 Text & Content

cat file Show file contents
head -n 5 file First N lines
tail -n 5 file Last N lines
echo "text" Print text
echo "text" > file Write to file
echo "text" >> file Append to file
grep word file Search in file
wc file Count lines/words
sort file Sort lines
uniq file Remove duplicates

⚙️ System & Utils

whoami Current user
hostname Machine name
date Current date/time
uname -a System info
uptime System uptime
history Command history
clear Clear screen
export VAR=val Set env variable
env Show environment
alias ll="ls -la" Create alias

🔗 Piping & Redirection

cmd1 | cmd2 Pipe output
cmd > file Redirect output
cmd >> file Append output
Tab Auto-complete
↑ / ↓ Command history
Ctrl+C Cancel command
Ctrl+L Clear screen
chmod 755 file Change permissions
du Disk usage
df Disk free space
